# Google Play Store App Insights

## Project Overview

This project analyzes Google Play Store app data using Tableau to understand app ratings, installs, reviews, categories, genres, content ratings, pricing, app size, update trends, and user sentiment.

## Objectives

- Analyze app ratings and review patterns.
- Compare free and paid applications.
- Identify the most installed apps and categories.
- Analyze app size and its relationship with installs.
- Compare ratings across categories, genres, and content ratings.
- Analyze app update trends over time.
- Compare high-rated and low-rated apps using user review sentiment.
- Build an interactive Tableau dashboard to present key insights.

## Tools & Technologies

- Tableau
- Microsoft Excel / CSV
- GitHub

## Dashboard

The Tableau dashboard includes:

- Average Rating
- Unique Categories
- Apps Rated 4.0 and Above
- Free vs Paid Apps
- Top 5 Most Installed Apps
- Top 5 Categories by Installs
- Top 10 Highest-Rated Apps
- Sentiment Analysis
- App Update Trend
- Top 10 Apps by Reviews

The dashboard also includes interactive filters that allow users to explore the data dynamically.

## Dataset

The analysis uses Google Play Store app data containing information such as:

- App
- Category
- Rating
- Reviews
- Size
- Installs
- Type
- Price
- Content Rating
- Genres
- Last Updated
- Current Version
- Android Version

A separate user-review dataset was used for sentiment analysis.

## Key Insights

- The overall average app rating is approximately **4.19**.
- The dataset contains **34 unique app categories**.
- Thousands of apps have ratings of **4.0 or above**.
- Free applications make up the majority of the app dataset.
- Games and other major categories account for a significant share of installations.
- App ratings, reviews, installs, and sentiment provide useful perspectives for evaluating app performance.
